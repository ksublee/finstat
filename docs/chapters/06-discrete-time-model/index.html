## 개요

이항나무와 같은 이산시간 모형을 이용해 자산 가격과 파생상품 가격을 설명한다.

## 학습 목표

- 이항모형의 구조를 이해한다.

- 복제 포트폴리오와 무차익 가격 결정을 연결한다.
