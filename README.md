# 금융통계학 웹북

금융통계학 강의자료를 Quarto 기반 한국어 웹북으로 재구성하는 프로젝트입니다.

이 웹북은 PDF 교재를 그대로 옮기기보다, 웹 환경에 맞게 수식, 그림, 코드 예제, 실습, 개념 설명 링크를 함께 제공하는 것을 목표로 합니다.

GitHub 저장소: [ksublee/finstat](https://github.com/ksublee/finstat)

## 읽는 방법

각 장은 금융통계학의 주요 주제를 순서대로 다룹니다. 본문에서 필요한 기초 개념, 용어, 기호 설명은 별도 페이지로 연결합니다.

## 구성

- `chapters/`: 장별 웹북 본문
- `concepts/`: 기초 개념, 용어, 기호 설명
- `examples/`: 계산 예제
- `labs/`: 실습 자료
- `assets/`: 그림과 스타일 등 웹북 자산

## 미리보기

Quarto가 설치된 환경에서는 다음 명령으로 미리볼 수 있습니다.

```powershell
quarto preview
```

전체 렌더링은 다음 명령으로 실행합니다.

```powershell
quarto render
```
